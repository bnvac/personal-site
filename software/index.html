    stdnt.xyz

    JavaScript · Repository private

    A searchable directory of everything a student can get for free — software packs, AI tools, free API keys, 115 scholarships and 224 STEM programmes — built so that community spreadsheets that quietly stop being updated have somewhere permanent to live. A quiz matches scholarships and programmes to your own circumstances entirely on-device; deadlines export to a calendar; saved items and quiz answers never leave the browser. Zero dependencies and no build step, so it deploys anywhere static.

    artwork

    JavaScript

    A pomodoro timer whose background is a museum painting that paints itself for exactly as long as you work. It starts on a bare toned canvas and lays down about fourteen thousand brush strokes one at a time, each travelling along its path and curving with the local image gradient, six passes from broad bands to fine points, the last landing as the clock reaches zero. Pictures come from seven open museum collections — the Met, the Rijksmuseum, the Prado, the Louvre and others — with a wall label for each. Everything you sit through is hung in a gallery of your own, repainted stroke for stroke from a forty-byte seed.

    baselayer

    JavaScript

    A NixOS configuration builder that runs entirely in the browser. Pick what the machine is for, a desktop, packages, self-hosted services and how locked down you want it, and it emits real flake.nix and configuration.nix files. Fifty-nine services are generated from their actual NixOS modules, with ports collected into the firewall and dependencies pulled in automatically; package search queries the same index as search.nixos.org; and a conflict checker catches things like a hardened kernel against the NVIDIA driver, or two services fighting over port 80. There is no backend — the configuration is compressed into the URL, so the link is the config.

    backoffice

    Go

    A self-hosted inventory for the parts in a lab drawer — boards, sensors, modules, passives — with photos, counts, locations, printable QR labels, and project bills of materials that tell you what you are missing. It ships as one static binary with templates and assets compiled in, one SQLite file and a folder of photos: no database server, no Node build, no config file, and it cross-compiles to a Raspberry Pi with no runtime dependencies at all. Upgrading is replacing the binary; the schema migrates itself on startup.

    intraweb

    Rust

    A local intranet that needs no internet, no servers and no setup. Run one binary on the same Wi-Fi and nodes find each other in about a second, over mDNS and a UDP broadcast beacon at once because so many networks quietly break one of them. You are an Ed25519 keypair and a folder; a hub hands out addresses and never stores or relays anyone’s content. Pages, signed mail with attachments that stay with the sender until fetched, end-to-end encrypted private channels, guestbooks and self-governing groups all run peer to peer. With no router at all, a $5 ESP32 becomes the network.

    Hearth

    Nix

    A private Linux distribution for engineers, built on NixOS. Open AI models and a voice assistant run privately on the local GPU through Vulkan, including mid-range AMD cards; laptops drop into a frugal power mode the moment they are unplugged; Tor mode refuses anything that would leak instead of letting it through; KiCad, FreeCAD, a slicer with real printer profiles and networked Klipper printers come built in. Seventeen modules switch on and off with one command, and a desktop and a laptop share one configuration and stay in step.

    Smart Shelf

    Python · Django

    Stock control for a food pantry. Volunteers fill in a shelf sheet or photograph a sorted pile and confirm the draft; every movement goes into an append-only ledger. A forecast built on weekly outflow, never on client records, works out what runs out and when, and publishes a “what we need” list to the pantry’s website.
