Built for anyone who shares a shelf

A group, a few machines, and nobody remembers which drawer the last one went in.

School makerspaces

Named logins with an activity log, so you know who took the last servo. QR labels on every bin.

Robotics teams

Projects reserve their parts, so the build team sees what's actually free. BOMs import from KiCad and EasyEDA.

Community labs

One page that tells visitors what each printer can print before they try.

Repair cafés

Firmware images and flash commands kept with each board, so someone else can repeat a fix.

Hardware startups

Price history per shop and real delivery times for planning a build. Backups are one file.

Home labs

Machines, install images, checksums and the power bill, next to the parts that built them.

Photos from Unsplash.

Small on purpose

One Go binary, one SQLite file, one folder of photos. No database server, no npm install, no config. Upgrading is replacing the binary.

Written rather than imported: a KiCad footprint parser and renderer, an STL parser with a z-buffer rasteriser, and a paste-a-list parser for tools and plans.

An AI model is optional (Ollama, OpenAI-compatible or Anthropic), and anything it suggests is checked against the real inventory before you see it.
