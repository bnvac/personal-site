Pick what the machine is for: a desktop, the packages you use, the services you want to host and how locked down it should be. baselayer writes the flake.nix and configuration.nix for you, ready to install.

How it works

Everything happens on the page. Nothing is uploaded, and there is no account.

Choose, don't type

Start from a bundle like a home media server or a locked-down laptop, then change anything step by step. Package search uses the same index as search.nixos.org.

Real files out

Services come from their actual NixOS modules. Ports go into the firewall and dependencies come along. A checker flags conflicts, like two services on port 80.

The link is the config

Your choices are packed into the URL. Send someone the link and they see the same machine. A one-line installer writes the files onto a fresh system.
