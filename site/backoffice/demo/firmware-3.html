Putting it back on

From the machine the board is plugged into, with the file downloaded next to you. This app does not flash anything itself — the board is on your desk, not on the server.

Hold BOOTSEL (or double-tap reset on most other UF2 boards) while plugging it in, then copy the file onto the drive that appears. It reboots by itself when the copy finishes.
